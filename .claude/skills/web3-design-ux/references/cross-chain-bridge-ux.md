# Cross-Chain Bridge UX

Designing bridge experiences for moving assets between blockchains.

## Bridge Basics

**What users need to know:**
- Moving assets between chains
- Costs time and money  
- Has risks
- Involves locking/minting mechanism

## Best Practices

1. Explain what bridging means
2. Show all costs upfront
3. Provide time estimates
4. Communicate risks clearly
5. Track progress visibly
6. Offer canonical vs fast options
7. Handle stuck bridges
8. Link to bridge explorer
9. Confirm arrival on destination
10. Educate about bridge types
