# Claude Design Skills

A comprehensive collection of specialized design skills and resources for building user experiences with AI agents, with a focus on Web3, DeFi, financial services, and agent UX patterns.

## 📦 Skills Included

### 1. Agent UX Design Skill (`agent-ux-design.zip`)

Complete UX design guidance for AI agents with professional templates and evaluation frameworks.

**Covers:**
- Microsoft agent UX principles (Space, Time, Core)
- Financial services design patterns (portfolio, transactions, compliance)
- Crypto/blockchain interaction patterns (DeFi, wallets, security, gas fees)
- Conversational design patterns (intents, flows, handoffs)
- Comprehensive evaluation framework (10 evaluation dimensions)
- Professional templates:
  - Flow design templates
  - Evaluation checklists
  - Design critique frameworks
  - Handoff patterns

**Best for:** Product designers, UX researchers, and AI/agent product teams building financial and crypto applications.

### 2. Web3 Design & UX Skill (`web3-design-ux.zip`)

Comprehensive Web3 and Ethereum dApp design guidance based on ethereum.org documentation and industry best practices.

**Covers:**
- 7 heuristics for Web3 interface design
- DEX (Decentralized Exchange) design patterns
- NFT marketplace design
- DAO governance interface design
- DeFi (Decentralized Finance) patterns
- Wallet design & self-custody UX
- Gas fee and transaction cost UX optimization
- Multi-chain design considerations
- Mobile Web3 design patterns
- Accessibility for blockchain applications
- Security and trust in Web3 UX

**Structure:** 
- 16 comprehensive reference files
- 6 professional design templates
- Full SKILL.md documentation

**Best for:** Product designers, UX researchers, blockchain developers, and teams building Web3 applications.

## 🚀 Getting Started

1. **Extract the skills:**

   - Check templates for practical starting points

3. **Apply to your project:**
   - Adapt the patterns to your specific domain and use case
   - Use templates as starting points for your design documentation

## 🎯 Key Patterns & Principles

### From Agent UX Design:
- **Space principle:** How agents organize information and UI elements
- **Time principle:** Agent interaction flow and response patterns
- **Core principle:** Agent personality and communication style
- **Handoff patterns:** Transitioning between agent and human assistance

### From Web3 Design:
- **Transparency:** Clear display of costs, permissions, and transaction details
- **Reversibility:** Ability to review and confirm actions before execution
- **Feedback:** Immediate and clear confirmation of user actions
- **Mental models:** Aligning with user understanding of blockchain concepts
- **Security mindset:** Design that encourages secure user behavior
